# Contributing

First off, thank you for considering contributing to this project! ❤️

Whether you're fixing a bug, improving documentation, enhancing accessibility, or proposing a new feature, every contribution is appreciated.

---

## Before You Start

Please:

- Search existing issues before creating a new one.
- Open an issue first for large changes or feature proposals.
- Keep pull requests focused on a single change.
- Follow the existing project structure and coding style.

---

## Development Workflow

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
```

3. Create a new branch.

```bash
git checkout -b feature/my-feature
```

4. Make your changes.

5. Test your changes in multiple browsers if applicable.

6. Commit using clear commit messages.

Example:

```text
feat: add animated skill cards
fix: resolve mobile navigation issue
docs: improve installation guide
```

7. Push your branch.

```bash
git push origin feature/my-feature
```

8. Open a Pull Request.

---

## Code Style

### HTML

- Use semantic HTML.
- Keep accessibility in mind.
- Use meaningful class names.

### CSS

- Mobile-first approach.
- Prefer CSS custom properties.
- Keep selectors readable.
- Avoid unnecessary specificity.

### JavaScript

- Use modern ES6+ syntax.
- Prefer `const` over `let` when possible.
- Use descriptive variable names.
- Avoid global variables.
- Comment only complex logic.

---

## Pull Request Checklist

Before submitting:

- [ ] Code follows project style
- [ ] Tested locally
- [ ] No console errors
- [ ] README updated (if needed)
- [ ] Screenshots added for UI changes
- [ ] No unnecessary files included

---

## Reporting Bugs

Please include:

- Browser and version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

## Suggesting Features

Feature requests should explain:

- The problem you're trying to solve
- Your proposed solution
- Possible alternatives
- Additional context

---

## Questions

If you're unsure about anything, feel free to open a discussion or issue before starting work.

Thank you for helping improve this project! 🚀
